 RK3588 上建议走 Rockchip 官方 RKLLM 工具链：PC 端把模型转换成 .rkllm，开发板用 RKLLM Runtime 调用 NPU。官方当前支持 RK3588，以及Qwen2/Qwen2.5/Qwen3/Qwen3.5、MiniCPM、Llama、Gemma、ChatGLM 等模型。官方仓库  (https://github.com/airockchip/rknn-llm) 最新版本说明 (https://github.com/airockchip/rknn-llm/releases/tag/release-v1.3.0)
- 可以看看`MiniCPM4-0.5`模型测试数据来自官方 benchmark，采用 RK3588、w8a8 量化、最大频率；实际速度会受内存、散热、上下文长度影响。官方性能表
  (https://github.com/airockchip/rknn-llm/blob/main/benchmark.md)

  交互方式也比较成熟：

  - 官方 C++ Demo 支持终端连续输入、多轮对话。
  - rkllm_server_demo 提供 Gradio 网页聊天界面。
  - Flask 服务兼容 OpenAI API：/v1/chat/completions，支持流式输出和 Function Calling。服务端示例
    (https://github.com/airockchip/rknn-llm/tree/main/examples/rkllm_server_demo)

  - 官方模型仓库提供转换好的模型下载，提取码是 rkllm。

  我的建议：

  - 4GB 内存：Qwen3-0.6B 或 MiniCPM4-0.5B
  - 8GB 内存：Qwen2.5-1.5B-Instruct 或 Qwen3.5-0.8B
  - 追求中文对话质量：优先 Qwen2.5-1.5B-Instruct
  - 追求响应速度：优先 MiniCPM4-0.5B
