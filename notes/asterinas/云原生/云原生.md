## 容器基本概念
- 容器
	- 一个视图隔离, 资源可限制, 独立文件系统的进程结合
- 镜像
	- 容器运行时所需要的所有的文件集合
## kubernetes
- k8s: 自动化的容器编排平台
	- 调度
	- 自动恢复
	- 水平伸缩
- 架构
	- Master
		- API Server: 所有组件与API server连接, 组件与组件之间不进行独立的连接, 一来与API server进行消息的传送
		- Controller
			- 完成对集群状态的管理
			- 自动修复和水平扩展都是他负责
		- Scheduler
		- etcd: 分布式的一个存储系统, 存储API Server的元信息
	- Node![[Pasted image 20260114200254.png]]
- pod
	- k8s的最小调度以及资源单元, 一组容器的抽象
	- 一个pod中共享同一个网络环境
- Volume
	- 声明在Pod中的容器可访问的文件目录
- Deployment
	- 定义一组Pod的副本数目, 版本等
- Service
	- 提供一个或者多个Pod实例的稳定访问地址
- Namespace
	- 集群内部的逻辑隔离
- API
	- HTTP + JSON/TAML
	- k8s api的spec
		- 希望pod达到的一个预期的状态
		- spec中有metadata `label`, 可以用来筛选
